Run AI-written code in the course notebook

Every lab asks you to run code on your own data file and enter three numbers. You do not need to install anything. The course notebook runs Python inside your web browser with JupyterLite, with pandas, NumPy, SciPy and Matplotlib ready. It needs no account and no login. This page shows the routine once; it is the same for all seven labs.

About 15 minutes the first time · use a laptop with Chrome, Edge, Firefox or Safari · a phone is too small for this work

01

Open the course notebook

A notebook is a page of cells. You type code into a cell and run it.

Open the course notebook

  1. The button opens start.ipynb in a new tab. It repeats Steps 1 to 3 of this page, so you can keep both tabs open.
  2. Click the first code cell (import os) and press Shift + Enter. The first run can take up to a minute while Python loads into your browser. The circle next to Python (Pyodide) at the top right is filled while it works. Later runs are fast.
02

Upload your lab file

Download your file from the lab first (Step 2 or Step 5). Each student's file is different.

  1. Drag the file from your Downloads folder onto the file list on the left of the notebook. Or click the Upload Files button (an arrow pointing up, above the file list) and choose the file.
  2. The file may open in its own tab as a table. Click the start.ipynb tab to go back.
  3. Check that it arrived. Run this cell again; your file name should be in the list:
import osprint(os.listdir())

Your files and notebooks are kept in this browser on this computer. They are still there when you come back, but not on another computer, in another browser, in a private window, or after you clear the browser data. To keep a notebook, use File → Download; to open it later, upload it like a data file.

03

Look at the raw file

Before any code from an AI, look at what the file really contains.

Replace the file name with yours. This prints the first 400 characters exactly as a program receives them:

print(open("my_file.csv", encoding="utf-8").read()[:400])

Note what separates the columns, how decimals are written, how a missing value looks, and the names of the columns. The AI needs these facts, and you need them to check its code.

04

Ask the AI assistant

Any assistant you are allowed to use. Give it the facts; ask for short code with an explanation.

Copy this request and fill in the three parts in brackets:

I have a CSV file named [file name]. Its first lines are:

[paste the lines from Step 3]

Write short Python code with pandas that prints these numbers, each with a label:

[copy the three questions from Step 5 of the lab, word for word]

The code runs in JupyterLite (Python in the browser). Use only pandas, numpy, scipy and matplotlib, and read the file from the current folder.

Explain each line of the code in one sentence.

Do not paste your name or student ID into the assistant. The file does not contain them, and the assistant does not need them.

05

Read, then run

The labs grade whether you can check code, not whether you can type it.

  1. Paste the code into a new cell. Read every line: what does it assume about the file? Does it treat missing values the way the lab asks?
  2. Run it with Shift + Enter.
  3. If it stops with an error, read the last line of the message, then find it in the table below. You can also paste the error and the code back to the assistant and ask what went wrong.
The last line saysIt usually meansTry
FileNotFoundErrorThe file is not uploaded, or the name in the code differs from yours.Upload again (Step 2); copy the exact name from os.listdir(). Keep the file in the same folder as the notebook.
KeyError: 'C6H6_ugm3'The code uses a column name that is not in your file.Compare with the first line of your file (Step 3).
Only one column, or numbers read as textThe separator or decimal mark in read_csv is wrong.Check sep= and decimal= against what you saw in Step 3.
NameErrorA cell that defines a variable or an import was not run.Run the cells from the top: Run → Run All Cells.
ModuleNotFoundErrorThe code needs a package that is not available.Ask the assistant for a version that uses only pandas, numpy, scipy and matplotlib. Tell it the code runs in JupyterLite.
Nothing happens, or the cell shows [*] for minutesPython is still loading, or the notebook stopped responding.Wait one minute. Then use Kernel → Restart Kernel and Run All Cells, or reload the page; your files stay.
06

Check the numbers, then enter them

Code that runs is not code that is right.

  • Count: does the number of rows match what you expect (for example 336 hours in 14 days)?
  • Range: is a concentration ever negative? Is a share between 0 and 100 %?
  • Hand: compute one value from five rows yourself and compare.

Then type your numbers into Step 5 of the lab before the reveal. The lab records whether you entered them first, and tells you which ones match. If one does not, find the line in your code that explains the difference: that is the most useful thing you will learn that week.

If the course notebook does not open on your computer, tell the instructor. The same code also runs in Google Colab or in any Python with pandas installed.
