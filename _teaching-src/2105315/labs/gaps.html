Check the AI's code

A student asked an AI assistant: "Fill the missing values in this file and give me the mean benzene." It returned this. It runs without an error and reports no missing values.

import pandas as pddf = pd.read_csv("benzene.csv", parse_dates=["datetime"])df["C6H6_ugm3"] = df["C6H6_ugm3"].interpolate()print(df["C6H6_ugm3"].isna().sum())   # 0: no gaps leftprint(df["C6H6_ugm3"].mean())

The code reports no missing values and a mean. What does it hide, and how would you notice?

Compare with the explanation

"0 missing" is true only because the code invented about 90 hours. Linear interpolation is reasonable across one missing hour. Across the three-day outage it draws a straight line from the last value before the gap to the first value after it, so three days of the daily cycle disappear: the mean can still look plausible, while the typical daily peak comes out too low.

You notice by counting what was filled before you trust the result, and by plotting the filled stretch: a straight line through three nights and three rush hours is not a measurement.

gap = s.isna().groupby(s.notna().cumsum()).transform("sum") filled = s.fillna(s.interpolate(limit_area="inside").where(gap <= 3))

Then report how many hours were filled, by which method, and how many remain missing.

    07

    Check your understanding

    Write first, then compare.

    Filling with the mean leaves the two-week mean exactly where dropping the gaps puts it. Why is it still a poor choice?

    Compare with the explanation

    Mean filling adds no information about the mean: it repeats the answer you already had. What it does add is a flat run of identical values with no daily cycle. Anything beyond the mean is now wrong: the daily peaks inside a long gap disappear, the spread of the data shrinks, and a later step (a standard deviation, a count of hours above a limit, a trend) treats invented hours as measured ones.

    Linear interpolation was close for single missing hours and far off for the three-day outage. What decides how long a gap it can bridge?

    Compare with the explanation

    How fast the quantity changes, compared with the length of the gap. Benzene follows traffic, so it rises and falls within a day; a straight line is a fair guess across one or two hours and a poor one across a rush hour or a night. A slow variable, such as a tank level, can be bridged for longer. You can test it on your own data the way this lab does: remove values you know, fill them, and measure the error.
